# Площадка совместного использования

## Назначения проекта

Проект предоставляет функциональную площадку для совместного использования различных вещей.
Например, пользователи могут совместно использовать один чайник, что очень полезно малоимущим пользователям в условиях тотальной нищеты и сближенности пользователей по месту жительства.

Проект помогает фиксировать используемые предметы в предоставляемой системе учета. Данный функционал необходим для того, чтобы вещь не потерялась после сотен передач, а каждый пользователь мог ответить на вопрос - "у кого конкретно в данный момент находится предмет?".

## Целевая аудитория

Целевой аудиторией данного проекта являются группы малоимущих граждан проживающих в общежитиях или коммунальных квартирах.
Данная группа пользователей существует в таких условиях, в которых совместное использование вещей является обязательным для выживания и экономии средств в условиях их крайней ограниченности.

Общинная форма жизни делает совместное использование вещей удобным. Пользователю не требуется далеко ходить, сосед по квартире находится в той же или соседней комнате.

## Предметная область

Процесс передачи предмета из рук в руки с системой контроля владения

## Основные сущности

Сущности - элементы базы данных проекта.
В базе данных присутствуют следующие сущности

1. Пользователь - зарегистрированный в системе пользователь предмета. 
2. Вещь - предмет, используемый для передачи.
3. Запрос - сохраненная в базу данных форма запроса пользователя для получения вещи
4. Передача - сохраненная в базу данных форма о передачи вещи от пользователя к пользователю

## Основные функции

main() - главная функция, выполняющая обработку других главных функкций.
do() - функция обрабатывающая действия пользователя, отвечает за вывод возможных действий и их обработку(косвенно)
login() - функия отвечающая за логин и создание пользователя
